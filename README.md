# pessimists-archive

Scored historical cases of a new thing meeting a prediction about it — fears that proved wrong
(the Pessimists Archive: 779 clippings, 493 headlines, 95 newsletter posts) and warnings that proved
right (researched). `build_db.py` → `pessimism.duckdb` (gitignored). Model: [DATA_MODEL.md](DATA_MODEL.md).
Skill: `~/.claude/skills/pessimists-archive`.

Source material is Louis Anslow & Jason Feifer's Pessimists Archive (pessimistsarchive.org); kept for
private research, not republished.
